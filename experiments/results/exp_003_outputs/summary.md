# Experiment 003 — Bounded Associate Class Grouping

## Purpose

This experiment groups bounded sample elements of $(\mathbb{N}_0[q]\setminus\{0\}, \cdot)$ into **sample associate classes** using units detected from Experiment 002. Two nonzero elements $a, b$ are associates if there exists a unit $u$ such that $a = ub$. The experiment uses units from `theoretical_units_n0q` restricted to those present in the sample, then partitions via BFS. This supports Exercise 1.7 and prepares for IDF analysis, where factorizations are always considered up to associates.

## Bounded Warning

> **This is a bounded computational sample. It does not prove the complete associate-class structure of the infinite monoid.**

Bounded samples may split a true infinite associate class into smaller visible classes if some unit multiples lie outside the generated sample.

## Parameters

- `max_degree = 5`
- `max_coeff = 3`
- `max_abs_unit_exponent = 5`
- Sample generated by `generate_n0_q(q, max_degree, max_coeff)` from `semirings.py`
- Units from `theoretical_units_n0q(q, max_abs_unit_exponent)` restricted to sample
- q values tested: 2, 1/2, 1/6, 3/2, 2/3, 4/9, 5/3

## Interpretation

**q ∈ ℕ (q = 2):** The only unit is $1$, so every element is its own associate class. All sample associate classes are singletons.

**q = 1/2:** Units include $\{1, 2, 1/2, 4, 1/4\}$ within the sample. Elements that differ by a power of 2 fall into the same associate class. The presence of non-singleton classes is consistent with the theoretical unit group $\langle 2 \rangle \subset \mathbb{Q}_{>0}$.\n\n**q = 1/6:** Units include products of powers of 2 and 3 within the sample. Associate classes are larger than the q=1/2 case because more units are available.

**q = a/b with a, b > 1:** Exercise 1.7 states the only unit of $(\mathbb{N}_0[q]\setminus\{0\},\cdot)$ is $1$. All sample associate classes are singletons.\n\n**Associate classes are necessary for UFM and IDF analysis.** Unique factorization is always considered up to unit multiples (up to associates). Without classifying associate classes, length sets of factorizations are not well-defined in the monoid-theoretic sense.
